# BrightPath Academy (Demo Project)

**This is a fictional demo website. It is not a commissioned client project, and all details (phone, address, timings, courses) are made up.**

A simple, mobile-friendly website for a sample coaching academy, built to practise web development.

## Live demo
https://praveenpraveen5125-prog.github.io/Brightpath-academy/

## Features
- Home, About, Courses and Timings, and Contact sections
- Menu links that jump to each section
- WhatsApp enquiry button (placeholder number in this demo)
- Mobile-friendly layout

## Built with
- HTML
- CSS
- GitHub Pages (free hosting)
